# Glasswren Weather Mast — Design Package

Released design package for the **Glasswren Weather Mast, Revision 1** (internal design ID
`GWM-1`).

## What is included
- `hardware/` — controller PCB and RS-485 backplane (KiCad 8)
- `firmware/` — RS-485 polling and sensor power management firmware
- `docs/` — bill of materials and site preparation guide
- `enclosure/` — mast clamp and junction box notes

## Release status
The GWM-1 package is released and all files are final. The clamps and controller in this
repository match the units shipped in October 2026.
